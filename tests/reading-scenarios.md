# Paper Research Lab v1.1.0 — Manual Smoke Scenarios

用于升级时的**行为验收**。这些是虚构的论文描述，**不是已审读的真实论文或自动运行结果**。操作：把每条描述交给安装后的 Skill，核对「预期路由」和「不得发生」是否满足；此清单不能证明某个 LLM 运行时一定遵守指令。

| 场景（模拟） | 预期主类型 / 核心证据 | 重点结果 | 不得发生 |
|---|---|---|---|
| 1. 用合成 LR 训练 sRGB-to-sRGB Diffusion SR，称画质更真实 | ML + SR / 图表、测试图、消融 | 区分相机退化与感知指标，检查真实 LR 外推 | 假装有 RAW 传感器真值；以 LPIPS 证明细节真实性 |
| 2. 无实验图的收敛性定理论文 | 理论 / Theorem、Lemma、Proof | 量词、假设、证明跳步、反例卡 | 追问训练数据、种子数或 p-value |
| 3. CUDA 内核称 2× 加速，只有 microbenchmark | 系统 / 端到端性能与质量证据 | 内核 vs 全链路、硬件与精度、重复测量 | 宣称实际产品端到端必然 2× |
| 4. Difference-in-Differences 估计某政策对事故率影响 | 因果 / 图表、识别假设、敏感性分析 | estimand、平行趋势、同期干预和分组 | 以统计显著证明全部因果假设 |
| 5. 临床 RCT 宣称新治疗安全有效 | 临床 / 随机化、结局、伤害记录 | CONSORT 2025 是报告规范；检验对照、失访和伤害 | 将单一研究当作患者个人治疗建议；忽略伦理 |
| 6. 15 人访谈中的主题分析 | 定性 / 引语、编码、负案例 | 材料→主题链、反身性与迁移范围 | 强制随机对照、对主题进行 p-value 打分 |
| 7. 综述汇总不同 SR benchmarks，评出全球最佳算法 | 综合综述 / 检索、协议与主张 | 逐项核对可比性与选择偏倚 | 无协议对齐就跨论文排名 |
| 8. 一篇论文把临床效果测试和访谈结合 | 临床 + 定性 / 两条独立证据链 | 分别评估疗效与定性解释，记录整合方式 | 用访谈代替临床效果证据 |
| 9. 仅有论文 abstract，没有 Figure / Table | 按题型路由，来源覆盖为摘要级 | 提出暂定判断、将证据缺口标 `[U]` | 声称逐图审核完成或编造图表数据 |

## 手工判定准则

- 输出「研究类型 + 主张类型 + 按需加载的专项 reference」。不相关清单没有强行调用。
- 若确有图/表：逐一回答固定六问并说明实际看到了多少；无图论文转为证据单元六问。
- 研究卡从具体证据缺口出发，包含可行的验证/反驳方式、判据和转向条件；不能强加不适用的数据/训练字段。
- `[P/A/R/U]` 有一致含义；原文没写的动机和反事实是审读者推断，缺少 PDF/图像时显式限定。
- 只声称**真正执行过**的检查；完整 `standard` 工作量较大时按文件分步完成，不在短回答中假装已审读全部图表。
