## Card {{n}} — {{actionable_name}}

**优先级：** 高/中/低　**依据：** 区分能力、成本、复现难度、项目相关性

| 字段 | 内容 |
|---|---|
| **来源 / Gap** | Paper ID + Fig/Table/§/页 + 未证实内容 |
| **Research Question** | 一句可被观察、推导、反例或系统检索回答的问题 |
| **Hypothesis / Conjecture** | `[R]` 方向性预测、猜想或待验证解释 |
| **替代解释 / 反命题** | 无差异、另一个机制、反例或竞争性解释 |
| **最小验证（MVT）** | 实验 / 证明 / 反例 / 访谈负案例 / 独立验证；列可执行步骤 |
| **Baselines / Controls** | 竞争理论、必要对照/消融、强基线；不适用时解释 |
| **材料、资源及许可** | 数据/文献/样本/形式化假设、许可/隐私/伦理边界 |
| **证据判定标准** | 指标与区间、证明义务、负案例解释或其他适用规则 |
| **成功门槛（预先规定）** | 数值/统计、证明完成条件或证据质量；无依据时标“待校准” |
| **失败与停止规则** | 具体什么结果触发放弃、缩小问题、改变假设 |
| **资源与风险** | 计算/取样/审批/时间、实现依赖及主要失败模式 |
| **第一步** | 最小成本、最大信息增益的下一动作 |
