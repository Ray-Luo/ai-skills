## Card {{n}} — {{actionable_name}}

**优先级：** 高/中/低　**依据：** 区分能力、成本、复现难度、项目相关性

| 字段 | 内容 |
|---|---|
| **来源 / Gap** | Paper ID + Fig/Table/§/页 + 未证实内容 |
| **Research Question** | 一句可被观测比较回答的问题 |
| **H1** | `[R]` 方向性预测 + 假设机制 |
| **H0 / 替代解释** | 结果无差异、或由别的因素导致 |
| **最小实验（MVE）** | 明确步骤：数据、拆分、模型、训练/推理、干预 |
| **Baselines / Controls** | 匹配预算的强基线、必要负对照和最关键消融 |
| **数据及许可** | 数据来源、量、标签、分布、许可/隐私风险 |
| **主/次指标** | 比较方向、报告方差/区间、必要人工质量检查 |
| **成功门槛（预注册）** | 数值/统计 + 效率/实际价值阈值；无依据时标“待校准” |
| **失败与停止规则** | 具体什么结果触发放弃、缩小问题、改变假设 |
| **计算与风险** | GPU/时间量级（若可估）、实现依赖、主要失败模式 |
| **第一步** | 最小成本、最大信息增益的下一动作 |
