# Paper Research Lab｜研究路径 × 证据审查 × 下一步实验

## 目标与总原则

不要只做论文摘要。把读论文变成三段可检查的研究工作：**重建论证路径 → 检查证据 → 设计下一步**。先给一个明确但可修订的判断，然后展示理由、证据边界和反事实设计。

**严格区分以下标记（贯穿所有笔记）：**
- `[P] 论文报告的事实`：作者明确写出或图表报告的内容；只代表“论文中如此报告”，不等于已独立验证。
- `[A] 作者的解释`：作者对观察结果、原因、机理或重要性的解释。
- `[R] 审读者推断`：本 skill 基于证据作出的解释、合理替代解释或反事实预测；不是作者已证实的事实。
- `[U] 未核实/缺失`：原文或材料没有找到、图无法读取、实验没有覆盖的部分。

每个关键数字、结论、方法细节标出可追踪的位置（章节、页码、公式编号、Figure/Table/Panel、Appendix/Supplement）。找不到来源就用 `[U]`，**不补造数字、作者动机、对照实验或图像细节**。只看摘要时明确标记为摘要级判断；只能看到 caption 时不得声称检查过图本身。

## 触发与模式

当用户说“读这篇 paper / 解释论文 / 检查图表 / 找 research gap / 分析 ablation / 复现实验 / 对比论文 / 从论文想下一步研究”等时使用。按意图选择模式，避免无意义的冗长输出：

| 模式 | 触发 | 工作范围 |
|---|---|---|
| `quick` 快速筛选 | 值不值得读、核心创新是什么 | 初步结论、逻辑链、最重要证据和未读部分；不得伪装完成逐图审计 |
| `standard` 完整精读（默认） | 读一篇论文 | 三层全流程；**检查所有可获得的正文图表**，相关补充图表按证据需要检查；产出分开的笔记 |
| `deep` 审稿级 | 严格批判、复现、投稿前评估 | `standard` + 可获取补充图表、实验配置、统计/实现细节、反事实对照设计 |
| `figure` 图表聚焦 | 指定 Figure / Table / Panel | 严格六问，向前后关联主张，更新证据矩阵中受影响的结论 |
| `compare` 跨论文综合 | 比较多个 papers | 统一任务/协议后对齐论点、证据、互相冲突点、可验证问题与实验优先级 |
| `math` 公式深读 | 不理解某个目标函数、推导 | 定义符号、逐步推导、直觉、隐含假设、与实际训练/推理行为的关系 |

如无明确模式，选 `standard`；若用户明确要求简短解释，则优先 `quick`。不得因篇幅限制跳过必做工作：可以把详尽内容放在独立文件，聊天只展示导航和要点。不要要求用户重复已经提供的论文或研究目标。

## 步骤 0：建立来源与阅读边界

1. 识别标题、作者、年份、链接/DOI/arXiv、版本、论文类型、用户关心的问题；只记录找到的元数据。
2. 优先读取用户提供的论文正文/PDF → Supplement/Appendix → 官方代码/实验配置；外部博客/第三方解读仅作补充，须明确来源。
3. 若 PDF/网页可以显示图像，**查看图和各个 panel 本身**，不只看 OCR 文本和图注；读取纵横轴、图例、单位、刻度、error bars、测试条件。缺图则说明未检查。
4. 记录阅读覆盖范围：全文/部分、已检查图表数量（若可数）、Supplement 是否可用、代码是否查看。不可访问就标 `[U]`，不假装完成。
5. 按研究类型加载 [研究类型审查清单](references/research-type-checklists.md)；对超分/图像复原/NVS 论文另外加载 [视觉与 SR 清单](references/vision-restoration-sr.md)。不要用 ML benchmark 标准机械套用到理论论文。

## 步骤 1：第一层——重建研究过程（Research Reconstruction）

### 1A. 先给可修订结论

在审计前先给读者：**一句话结论、最重要贡献、最关键条件/风险**，显式标注为“预判（待证据审计）”。先回答“它想改变我们已知的什么”，再讲算法细节。只读到摘要时必须说明。

### 1B. 重建研究论证链

依次回答：
1. **已有认识（Prior knowledge）**：当时公认方法与已知限制是什么？依据哪些前作？
2. **研究缺口（Gap）**：具体哪一项能力、证据或解释缺失？是真实未解决问题，还是作者的 framing？
3. **可检验假设（Hypothesis）**：作者实际上预测了什么可观察变化？论文没写明时标记 `[R] 重建的假设`。
4. **方案与机制（Proposed mechanism）**：什么设计可能使假设成立？把“方法是什么”和“为什么可能有效”分开。
5. **验证（Tests）**：哪些数据/模型/对照/指标/消融检验哪些假设？
6. **结果与论证跳跃（Inference）**：作者从观察结果走到了什么结论？哪一步可能超出数据？

**重要**：这里重建的是论文呈现的“逻辑研究路径”，不等于作者真实的时间顺序、心理动机或实验历史。只有作者明确回顾过真实探索史，才能将其称为真实研究经过。

### 1C. 决策点账本（Decision Ledger）

至少覆盖对结果敏感的选择：研究问题的操作化、数据及筛选、预处理、建模/架构、损失函数、训练预算、baseline、指标、推理设置、统计检验。每个**关键**选择写：

`选择 → 原文依据/出处 → 其他合理选择 → 可能导致的变化 [R] → 最小验证实验 → 什么观察会否定该预测`

对作者已做的替代实验标 `[P]` 并注明 Figure/Table；**未做的反事实仅给方向性假设，不能写成已证实结果**。重点讲最有信息量的 3–5 个选择；其它决策可以收在详细账本。

## 步骤 2：第二层——证据审查（Evidence Audit）

### 2A. 核心主张与证据矩阵

从 Abstract、Introduction 和 Conclusion 抽取每一条**独立的核心主张**（方法有效、优于 SOTA、泛化、机制成立、效率提升等）。逐条记录：

`主张 → 性质 ([P]/[A]/[R]) → 证据位置 → 直接/间接证据 → 成立条件 → 可能替代解释 → 审查状态`

审查状态仅选：`支持` / `部分支持` / `证据不足` / `与证据冲突` / `无法核实`。不能把“统计显著”直接等同于“大效应、可靠、可泛化”；也不能把“未达显著”自动解释为“无效”。区分论文内部证据和外部独立复现。

### 2B. 图表固定六问（逐图逐表使用）

对每个**可获得的正文 Figure/Table**（必要时细化到 panel），都用完全一致的六问：

1. **为什么做？** 它要回答什么问题/排除什么解释？理由来自原文还是审读者重建？
2. **怎么做？** 数据、变量、干预/模型、对照、指标、样本、预算/设置是什么？
3. **怎么看？** 横纵轴、图例、方向、数值范围、单位、误差线、表格高低优劣如何读？
4. **发现什么？** 图表直接可见的观察值/差异是什么？不抢先写机制解释。
5. **支持到哪？** 最多能支撑哪一层结论？在什么条件成立、有哪些混杂/不确定性、不能支持什么？
6. **为什么接下一张图？** 当前证据留下什么悬念，下一图是否回应？若论文没有这样的论证连接，就明确写“未建立直接逻辑联系”，不要杜撰作者意图。

**不可省略图表编号及来源**。每个图表结束时给一句“这张图最值得学的研究设计选择”。读不到真实图形时注明“仅由图注/正文推断，无法核对视觉细节”。图表内容与正文叙述冲突要单独标记。

### 2C. 按研究类型评估有效性

参考 [研究类型审查清单](references/research-type-checklists.md)，将问题聚焦在该研究自身的证据逻辑上。对实证 ML 特别审查：baseline 公平性、数据污染/泄漏、消融控制、多个 seeds 与方差、超参/训练预算、外部数据泛化、规模效应、统计与实用意义、指标是否代表主张。对理论论文改查假设/定理/证明/反例；对系统论文改查负载与硬件环境、吞吐延迟、成本和可复现性。

审计结束，**更新步骤 1A 的预判**：写“修订后结论”，并列出有/没有改变的判断、最强证据、最大证据缺口与外推边界。

## 步骤 3：第三层——生成研究卡（Research-to-Experiment）

不是头脑风暴式堆点子；每个方向必须**溯源到至少一条明确的证据缺口或决策点**。默认生成 **1–3 张**按信息价值排序的卡；没有可靠缺口就写“暂不建议立项”，不要强行创新。

每张卡包含：
1. **来源与缺口**：Paper ID + 具体 Fig/Table/Section + 尚未回答的问题。
2. **可检验问题（RQ）**：收敛成可用观测比较回答的一句话。
3. **假设与机制（H1 / H0）**：预期方向、原因与合理替代解释，均标 `[R]`。
4. **最小可行实验**：数据来源/数量与拆分、处理流程、训练/推理设置、可复现实验步骤。
5. **对照与消融**：强 baseline、负对照/阳性对照（如适用）、一次只变一个关键因素；保证数据/预算公平。
6. **指标与判断标准**：主指标、次指标、误差/置信区间或合适验证规则、预先写清成功阈值与必要的定性检查。
7. **反证与停止规则**：**什么具体结果会让我放弃、缩小或转向这个方向**；包括质量、泛化、时间/计算成本边界。
8. **资源、风险与下一动作**：数据许可/标签/代码/GPU/预计复杂度、关键失败模式，以及能最快减少不确定性的第一步。

优先**最小但能区分两个解释的实验**（discriminating experiment），而不是直接投入大规模训练。把“方向有趣”与“证据支持立项”严格区分。

## 输出与知识沉淀

默认中文，关键术语同时提供英文；数学使用 LaTeX 并解释符号、假设和直觉。不要让用户在一个超长聊天回复里寻找图表或研究卡。

有文件能力时，**每篇论文分开生成**（参考 `assets/` 模板）：
- `notes/<paper-slug>/01_brief.md`：论文名片、**预判 → 研究路径 → 决策点 → 修订后结论**。
- `notes/<paper-slug>/02_evidence_audit.md`：核心主张矩阵、每个 Figure/Table 的六问、证据缺口、覆盖范围。
- `notes/<paper-slug>/03_research_cards.md`：1–3 张完整可检验的实验卡。
- 多篇论文时维护 `notes/paper_index.md`：链接、标签、类型、关键结论、可信边界、跨论文冲突、候选实验及状态。

在聊天里**先给紧凑导航（约 8–12 行）**：一行结论、修订状态、最重要证据、最致命缺口、最高价值研究卡和上述文件入口。用户点名某图/公式时只展开该单元，不重复整篇笔记。没有文件能力时按这四个标题分隔成可定位的短段落，优先输出已完成且可验证的部分。

详细的笔记布局见：[Brief 模板](assets/brief-template.md)、[证据审查模板](assets/evidence-audit-template.md)、[研究卡模板](assets/research-card-template.md)、[论文索引模板](assets/paper-index-template.md)。

## 跨论文连接

收到第二篇及以后：先比较**是否任务、数据切分、退化/干预、指标、预算和评测条件可比**。不可比就指出原因而非直接排行。把新论文接入三张地图：`已知结论与证据强度`、`冲突/未解决缺口`、`可复用的实验设计与反事实`。若提出研究方向，写明它综合了哪些论文证据及冲突。

## 交付前自检

- [ ] 有先行判断，也有审计后的修订；没有把两者混淆。
- [ ] 未把逻辑研究路径伪称为作者真实研究经过。
- [ ] 每个核心主张有原文定位、证据性质、成立条件或标注缺失。
- [ ] `standard/deep` 模式：每张实际可读正文图表均回答固定六问，未读部分明确列出。
- [ ] 反事实预测明确标 `[R]`，没有捏造作者做过的实验。
- [ ] 审查标准适合论文类型，不以单一 checklist 替代研究判断。
- [ ] 每个实验方向都追溯证据缺口，含对照、评判阈值和放弃条件。
- [ ] 先给短导航，深度材料分文件；没有虚构链接、数字或文献。
