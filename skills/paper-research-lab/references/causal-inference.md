# 因果推断与观察性实证专项审查（Causal Inference）

当核心主张含「X 导致 Y」「政策产生效应」「处理/干预提高结果」时加载，无论论文属于经济学、社会科学、教育还是医疗观察研究。**先问识别策略，而不是先看 p-value。**

## 从问题到可识别对象

- 明确 **estimand**：谁（population）、什么 treatment/intervention、相对什么 counterfactual、什么 outcome、什么时间窗；ATE/ATT/LATE 等不要混用。
- 明确数据生成与选择过程：抽样框、测量误差、缺失、失访、样本选择、处理选择、溢出/干扰、时间先后与可能的反向因果。
- 尝试用简洁 DAG / 因果结构说明混杂路径、collider、mediator；区分控制变量与因果调整所需变量。
- 对识别假设给出**可辩护证据及不可直接检验部分**：无未测混杂、平行趋势、排除限制、单调性、断点附近可比性等，随设计而定。

## 按方法检查

| 设计 | 首要审查 | 常见替代解释/诊断 |
|---|---|---|
| 随机试验 | 随机化实现、分配隐藏、偏离协议、失访 | 不平衡、依从性、选择性报告 |
| Difference-in-Differences / Event Study | 干预前趋势、组别组成、干预时点、异质处理效应 | 预趋势、错用加权估计、同期政策变化 |
| Instrumental Variables | relevance、exclusion、独立性、单调性 | 弱工具、直接路径、LATE 外推过远 |
| Regression Discontinuity | cutoff 操作、带宽/函数形式、断点两侧连续性 | 自选择、协变量跳跃、带宽敏感性 |
| Matching / Regression Adjustment | overlap/positivity、可观测混杂、模型设定 | 未测混杂、共同支持不足 |

## 证据、结果与边界

- 区分估计值、标准误、置信区间、实际意义；多重比较、聚类层级、样本量与模型规范选择有无说明。
- 报告敏感性分析、负对照、安慰剂、placebo cutoff、异质性与外部效度，不能把诊断通过称为“所有识别假设已被证明”。
- 观察性相关不支持因果时，写 `[U] 因果识别不足`；不把作者叙述自动采纳为机制解释。

## 研究卡

卡片写明 estimand、竞争因果解释、能区分二者的识别设计、可获取数据与时间窗口、稳健性诊断、成功/否定条件；若伦理或可行性受限，选择合理的自然实验或观测性检验，不能默认可随机干预。
